# Banda Sai Venkat — Portfolio

## Deploy on GitHub Pages
1. Create a GitHub repository, e.g. `Portfolio`.
2. Upload every file in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch** → `main` → `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Resume
The site expects `resume.pdf` in the same folder as `index.html`.
Both Resume buttons use a relative download path and the filename `Banda_Sai_Venkat_Resume.pdf`.
